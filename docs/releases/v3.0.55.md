## 🚀 Chi Tiết Bản Phát Hành (GitHub Release Description)

### 🌟 Điểm Nổi Bật (Highlights)

Phiên bản **v3.0.55** là bản phát hành lớn tập trung vào **hệ sinh thái Auto Plugin Generator v3 (CMS + SPA/API JSON + Ma trận Tiến trình)**, **tăng cường năng suất cho các Studio chuyên sâu (Translate, Workflow, Ebook, Tools)** và **nâng cấp toàn diện hiệu năng – trải nghiệm Shell**:

1. **Tạo Plugin Tự Động v3 — Hỗ Trợ SPA (React/Vue/Next.js), API JSON & Ma Trận Phân Tích Live**:
   - **Kiến trúc phân tích 3 tầng thông minh**:
     - *Tầng 1 (HTML & Phân trang)*: Nhận diện CMS chuẩn (NetTruyen, Madara + `/ajax/chapters/`, MangaStream `ts_reader.run`, TruyenQQ) và tự động phát hiện phân trang danh sách chương (`?page={page}`, `/page/{page}`, `/trang-{page}`).
     - *Tầng 2 (SSR / Embedded JSON)*: Trích xuất dữ liệu chương và ảnh từ `__NEXT_DATA__`, `__NUXT__` và script JSON nhúng (không dùng `eval`).
     - *Tầng 3 (CDP Network Sniffer)*: Tự động mở `BrowserWindow` ẩn kèm Chrome DevTools Protocol (có pre-warm target chống deadlock trên Electron 34) để bắt API JSON phân trang (`page`/`offset`) hoặc DOM render sau JS, tham số hóa thành `{mangaSlug}`, `{mangaId}`, `{chapterSlug}`, `{chapterId}`.
   - **Ma trận Tiến trình 8 bước Live (`0% → 100%`)**: Hiển thị trực quan từng giai đoạn (`Tải trang`, `CMS & Meta`, `Quét DOM`, `SSR JSON`, `CDP Sniffer`, `Mới cập nhật`, `Trích xuất ảnh`, `Hoàn tất`), bộ đếm thời gian chạy và nhật ký telemetry theo thời gian thực.
   - **Chạy thử Sandbox & Bảo mật**: Cho phép kiểm thử plugin mới tạo ngay trước khi cài (`testGeneratedPlugin`), bổ sung cảnh báo + hộp thoại xác nhận khi ghi đè plugin trùng ID, chặn Prototype Pollution ở helper sinh mã, và chuyển toàn bộ thông báo tab Plugin sang Toast nổi tự động ẩn (`3,5s` / `6s`).

2. **Khám Phá, Mới Cập Nhật & Quét Hàng Loạt Toàn Diện**:
   - Bổ sung hỗ trợ **Mới cập nhật (Latest Updates)** cho thêm **29 connectors**.
   - Mở rộng **Quét Hàng Loạt (Bulk Scan)** trên **47 connectors**, nâng giới hạn quét toàn danh mục lên **500 trang** và bảo toàn danh sách truyện đã quét được khi người dùng bấm Hủy giữa chừng.
   - Đồng nhất thẻ truyện dùng chung `MangaCard` giữa Khám phá và Thư viện ngoại tuyến; chuẩn hóa loading skeletons, nút dừng tác vụ và nút đóng/mở sidebar.

3. **Trang Chủ (Crawler), Hàng Đợi & Thư Viện Ngoại Tuyến (Offline Library)**:
   - Đồng nhất giao diện tab **Trang Chủ (Crawler)** theo chuẩn *Explore-First Unified UI* và tinh giản sidebar.
   - Thay thế màn hình Lịch sử cũ bằng **Error Inspector Portal** ngay trong Hàng đợi tải cùng tính năng xuất danh sách lỗi ra file **CSV**.
   - Quy hoạch **Offline Library** tập trung thuần túy vào quản lý thư viện đã tải về máy với bộ lọc sidebar đầy đủ, thẻ thống kê KPI và loading skeleton mượt mà.

4. **Dọn Trùng Lặp & Phát Hiện Quảng Cáo Thông Minh**:
   - Mặc định bật chế độ phát hiện **ảnh trùng lặp và ảnh quảng cáo/banner** thông minh kèm tối ưu hóa hiệu năng quét đa luồng.
   - Làm mới giao diện Duplicates Finder với Overview Card, Skeleton tải, Modal xem trước đồng bộ theo 12 Theme và tích hợp trực tiếp vào **Workflow Studio**.

5. **Translate Studio, Workflow Studio, Tools Studio & Ebook / Kindle**:
   - **Translate Studio**: Thêm Undo/Redo, phím tắt giữ để soi ảnh gốc (*Original Peek*), đồng bộ style & tìm/thay thế văn bản hàng loạt trên toàn bộ trang, tinh chỉnh bộ phím tắt thao tác chính xác.
   - **Workflow Studio**: Thêm Undo/Redo đồ thị, tắt/bỏ qua node (*Bypass*), bản đồ thu nhỏ (*Minimap*), tự căn khung (*Fit View*), phím tắt điều hướng và hiển thị telemetry từng bước chạy.
   - **Tools Studio & Image Pipeline**: Sửa lỗi nút bật/tắt panel xem trước (*Preview Panel*), căn chỉnh UX dãy thao tác và tinh gọn footer.
   - **Ebook Studio & Gửi Kindle**: Hợp nhất giao diện Convert với các sub-tab ngay trên sidebar, gom cấu hình định dạng gọn gàng, xử lý file atomic in-place an toàn hơn, và chuyển khung gợi ý nguồn EPUB/PDF ở tab **Gửi Kindle** sang cột sidebar trái.

6. **Hiệu Năng Ứng Dụng & Năng Suất Desktop (Shell)**:
   - Thực hiện **code-splitting** các studio lớn giúp giảm kích thước bundle khởi động và harden tiến trình Electron Main.
   - Thêm **Command Palette** (`Ctrl/Cmd + K`), hiển thị **tiến trình tải trên Taskbar**, **thông báo Desktop** khi hàng đợi hoàn tất, bộ lọc/tìm kiếm/sao chép **Console**, và điều khiển **Zoom** ngay trên `StatusBar` (kèm popover, HUD toast và lưu mức zoom bền vững).
   - Loại bỏ popup tự đọc clipboard gây gián đoạn trải nghiệm chuyển cửa sổ (`ClipboardUrlBanner`).
